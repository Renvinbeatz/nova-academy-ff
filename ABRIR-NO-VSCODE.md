# Abrir no VS Code

Abra a pasta que contém package.json. Use Node.js 22.x e pnpm 11.25.0.
No terminal, execute pnpm install e pnpm dev.
Para testar a versão de produção: pnpm build e pnpm start.

Os vídeos estão incluídos em videos-originais e são preparados automaticamente em public/videos antes do dev/build.
A aplicação usa Next.js e pode ser publicada na Vercel. Consulte README.md para atualizar o conteúdo e conhecer a limitação do gerenciador de uploads nesta hospedagem.
